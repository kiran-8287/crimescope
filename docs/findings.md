# CrimeScope — Evidence-Backed Findings

This document reports the five research investigations required for academic
submission. Every number below was generated by a single reproducible entry point,
[`scripts/research_findings.py`](../scripts/research_findings.py), which reads **only**
the active immutable release and the saved analysis run. It never refits production
models and never overwrites the run directory.

- **Active release:** `ncrb-districtwise-2021-2024-ecec48b772bc` (dataset sha256 `ecec48b772bc…`)
- **Active run:** `ncrb-national-2024-admin-log1p-zscore-20261107-v4`
- **Output directory:** [`analysis/output/findings/ncrb-national-2024-admin-log1p-zscore-20261107-v4/`](../analysis/output/findings/ncrb-national-2024-admin-log1p-zscore-20261107-v4/)
  (`findings.json`, `tables/*.csv`, `figures/*.png`)

**Reproduce everything:**
```bash
python scripts/research_findings.py
```
The script verifies nine hashes before parsing anything and exits non-zero on any
mismatch: three structural checks (SQLite vs release manifest, feature input vs run
manifest, release dataset vs run dataset) plus one hash check per consumed run artifact
(`pca/pca_2024.json`, the three saved `kmeans/kmeans_2024_k3|k4|k5.json`, `anomalies/
anomalies_2024.json` and `association/association_rules_2024.json`) against the run
manifest's recorded `artifacts` map; an artifact with no recorded hash fails closed.
All nine checks passed for this report (`checks` block in `findings.json`).

Two conventions are used by the saved pipeline and are **never mixed**:

- **PCA / K-means feature transform:** `log1p(x)` then per-feature z-score with
  **population** std (`ddof=0`).
- **Anomaly z-scores:** cross-sectional `(value − mean) / std` with **sample** std
  (`ddof=1`).

Interpretation boundaries that apply to every finding: these are **reported**
(registered) counts, not all crime; there are **no** safe/unsafe labels; no
population-adjusted rates are computed (no validated denominator); administrative
-district classification is partly inferred; name matching is an operational join and
is **not** evidence of boundary continuity; parent totals and their components
overlap (no false totals are formed); association rules describe reporting-unit
co-occurrence, not incidents, offenders or causation.

## Investigation 1 — Reporting volume and PCA

**Research question.** Do the two saved principal components mostly track overall
reporting volume, and what do the retained loadings describe?

**Scope.** 2024 national cohort of `administrative_district` reporting units:
**774 regions × 131 features** (source leaf and component categories; official and
parent totals excluded). Source: saved PCA artifact joined to the official 2024
total read straight from the release SQLite.

**Method.**
1. Read `components`, `explained_variance_ratio`, `cumulative_variance_ratio`,
   `eigenvalues` and `loadings` from [`pca/pca_2024.json`](../analysis/output/runs/ncrb-national-2024-admin-log1p-zscore-20261107-v4/pca/pca_2024.json).
2. Join each component's `region_id` to the 2024 official-total category
   (`bc8502a9f43a6fdcc5f71ad8`) in `crime_observations` by stable `geography_id`.
3. Pearson `corr(PC1, log1p(total))`, `corr(PC1, total)` and `corr(PC2, log1p(total))`.

**Verified results.**

| Quantity | Value |
|---|---|
| PCA regions / features | 774 / 131 |
| Joined observations / unmatched | **774 / 0** |
| Explained variance PC1 | **15.91 %** |
| Explained variance PC2 | **4.57 %** |
| Cumulative PC1+PC2 | **20.48 %** |
| Eigenvalues (PC1, PC2) | 20.870, 5.999 (total feature variance 131.169) |
| `corr(PC1, log1p(total))` | **−0.8774** |
| `corr(PC1, raw total)` | **−0.7069** |
| `corr(PC2, log1p(total))` | 0.1683 |

PC1 largest-|loading| features (all negative here): Vehicle Theft (−0.854), Other
Thefts (−0.837), Cruelty by Husband or Relatives (−0.810), Murder (−0.804), Robbery
(−0.795). PC1 positive loadings are tiny by comparison (largest, Terrorist act,
0.042). PC2 positive: Dowry Death (0.649), Kidnapping to compel marriage (0.600),
Grievous Hurt (0.433), Other Kidnapping & Abduction (0.427), K&A Adults (0.402);
PC2 negative: Affray (−0.520), Day Burglary (−0.516), Mischief (−0.483), Criminal
Trespass (−0.415), Obstruction on a public way (−0.405).

**Figure.** [`figures/inv1_pca_volume.png`](../analysis/output/findings/ncrb-national-2024-admin-log1p-zscore-20261107-v4/figures/inv1_pca_volume.png)
— PC1 vs log1p(total) with a least-squares line, plus a variance bar chart giving each
saved component's share of the **total** 131-dimension feature variance (PC1 15.91 %,
PC2 4.57 %) with the remaining **79.52 %** shown as one residual bar. Because the saved
artifact contains only two component values, this is a two-component share chart and
**not** a full scree plot.

**Plain-language interpretation.** PC1 is essentially a reporting-volume axis: large
units load strongly and uniformly negative, so the negative-PC1 direction means "many
reported cases" (the sign is a mathematical convention — flipping it changes nothing).
The two axes together retain only 20.48 % of the 131-dimensional variance, so a 2-D
projection is a **summary**, not a faithful copy of profile similarity. PC2 separates a
narrow set of offences against women/children (positive) from public-order and
property offences (negative); this split is supported by the loadings but is only a
secondary axis (4.57 %).

**Limitation / alternative explanation.** Correlation with log1p(total) is a
descriptive association, not proof that PC1 "is" volume; a genuinely higher count and a
higher reporting-propensity both raise the recorded total. **PCA did not isolate crime
composition from volume**, and closeness on the 2-D plot does **not** mean two units
have near-identical profiles.

**Sources / reproduction.** `pca/pca_2024.json`; SQLite `crime_observations`
(category `bc8502a9f43a6fdcc5f71ad8`, `region_type='administrative_district'`,
`measure_type='cases'`); `python scripts/research_findings.py` → `investigation_1` in
`findings.json`.

## Investigation 2 — Annual totals vs matched-unit change

**Research question.** How do annual reported totals move, and how much of the
2022→2023 movement survives when restricted to the same reporting units?

**Scope.** Official-total category, `region_type='administrative_district'`,
`measure_type='cases'`, years 2021–2024. Unit matching is an operational join on
`(state_name, region_name)`.

**Method.** Independently derive the annual set and, for the only source-connected pair
(2022–2023), the matched subset. Report absolute and percentage changes and reconcile
`annual = matched + excluded` per year.

**Verified results — annual (all eligible admin districts).**

| Year | Admin districts | Annual reported total |
|---|---|---|
| 2021 | 726 | 2,909,532 |
| 2022 | 750 | 2,808,408 |
| 2023 | 770 | 2,940,460 |
| 2024 | 774 | 2,740,258 |

2023 vs 2022 annual change: **+132,052 cases (+4.70 %)**.

**Verified results — matched 2022↔2023 cohort.**

| Quantity | Value |
|---|---|
| Matched units | **749** |
| Matched 2022 total | 2,804,254 |
| Matched 2023 total | 2,892,597 |
| Matched change | **+88,343 (+3.15 %)** |
| Excluded 2022 | 1 unit, 4,154 cases |
| Excluded 2023 | 21 units, 47,863 cases |
| Reconcile 2022 | 2,804,254 + 4,154 = 2,808,408 ✅ |
| Reconcile 2023 | 2,892,597 + 47,863 = 2,940,460 ✅ |

Excluded 2022 unit: Maharashtra · Osmanabad. Excluded 2023 units (21): Himachal Pradesh
· Nurpur; Maharashtra · Dharashiv; Nagaland · Noklak, Shamator, Tseminyu; Rajasthan ·
Anupgarh, Balotra, Beawar, Deeg, Didwana-Kuchaman, Dudu, Kekri, Khairtal-Tijara,
Kotputli-Behror, Neem Ka Thana, Phalodi, Salumbar, Sanchore, Shahpura; Tamil Nadu ·
Mayiladuthurai; Uttar Pradesh · Amroha. (Full lists: `tables/inv2_excluded_2022.csv`,
`tables/inv2_excluded_2023.csv`.)

**Figure.** [`figures/inv2_annual_vs_matched.png`](../analysis/output/findings/ncrb-national-2024-admin-log1p-zscore-20261107-v4/figures/inv2_annual_vs_matched.png)
— annual totals for 2021–2024 with the matched 2022–2023 cohort overlaid.

**Plain-language interpretation.** Restricting the comparison to the same named
reporting units reduces the measured increase from 4.70 % to 3.15 %. This controls
membership in the comparison set but does not establish unchanged reporting
boundaries, so it is not by itself evidence that the difference is caused by newly
created districts. The two figures must be read separately.

**Limitation / alternative explanation.** `(state_name, region_name)` matching is
operational only — a matched name is not proof of an unchanged administrative
boundary, and an unmatched 2023 name is not automatically a "new district" (it may be
a rename or a re-parented unit). 2023–2024 is **not** compared here because the IPC→BNS
reclassification makes the totals non-comparable; 2021–2022 is also not matched because
of intervening geography changes.

**Sources / reproduction.** SQLite `crime_observations`; `python scripts/research_findings.py`
→ `investigation_2` in `findings.json` and `tables/inv2_excluded_*.csv`.

## Investigation 3 — What distinguishes the clusters

**Research question.** What characterizes the saved k=3 clusters, using saved outputs
only?

**Scope.** Same 774 × 131 transformed 2024 matrix; saved k-means artifact
(`seed = 42`). No browser-side or in-document recomputation of memberships — the script
reproduces the transform only to describe the saved cluster centroids.

**Method.** Read `assignment_records` from
[`kmeans/kmeans_2024_k3.json`](../analysis/output/runs/ncrb-national-2024-admin-log1p-zscore-20261107-v4/kmeans/kmeans_2024_k3.json);
compute each cluster's official-total sum / median / IQR; read the standardized centroid
and record the most extreme features; pick representatives as the members nearest the
centroid (in fitted space).

**Verified results (k=3).**

| Cluster | Size | Total-cases sum | Median | IQR |
|---|---|---|---|---|
| C1 | 190 | 1,290,976 | 5,309 | [3,880, 7,974.5] |
| C2 | 168 | 53,129 | 159.5 | [39, 388.25] |
| C3 | 416 | 1,396,153 | 2,974.5 | [1,609.75, 4,360.25] |

- **C1** centroid-high features (z): Stalking 1.041, Day Burglary 1.040, Insult modesty
  of women 0.981, Affray 0.950, Criminal Trespass 0.917. Representatives (nearest
  centroid): Maharashtra · Gondia (7.82), Madhya Pradesh · Khandwa (8.17), Madhya Pradesh · Shahdol (8.20).
- **C2** centroid-low features (z): Murder −1.465, Vehicle Theft −1.413, Cruelty by
  Husband −1.358, Other Thefts −1.320, Rape −1.302. Representatives: Arunachal Pradesh ·
  Kameng West (2.27), Arunachal Pradesh · Kurung Kumey (2.86), Meghalaya · Garo Hills South West (2.87).
- **C3** centroid-high features: Grievous Hurt 0.340, Murder 0.328, Other IPC/BNS crimes
  0.297, Dowry Death 0.283, Attempt to Murder 0.271. Representatives: Chhattisgarh ·
  Mungali (5.70), Chhattisgarh · Manendragarh-Chirmiri-Bharatpur (5.77), Assam · Dhemaji (5.81).

**k diagnostics (inertia).** k=3 → 86,824.9 (sizes 190/168/416); k=4 → 85,964.0
(sizes 4/168/405/197); k=5 → 83,473.8 (sizes 4/167/372/192/39). k=3 is presented as the
**selected** model.

**Figure.** [`figures/inv3_cluster_totals.png`](../analysis/output/findings/ncrb-national-2024-admin-log1p-zscore-20261107-v4/figures/inv3_cluster_totals.png)
— official-total distribution per k=3 cluster and an inertia-vs-k line.

**Plain-language interpretation.** The clusters differ reproducibly in both magnitude
and mix: a high-volume group (C1, median ≈ 5,309 cases) with elevated women-safety and
public-order offences, a very-low-volume group (C2, median ≈ 160 cases) that is also low
on the largest volume offences, and a broad mid group (C3) with a flatter profile and
more interpersonal-violence weight. These are **profile similarities**, described against
the national-average reference (centroid z = 0).

**Limitation / alternative explanation.** Inertia falls mechanically as k rises, so it
is **not** a goodness-of-fit score and no "optimal k" is claimed. Clusters are not
urban/rural, safe/unsafe, or risk categories. The saved artifact stores no per-unit
distances, so representatives are labelled as the nearest saved members, not as the
"most typical" units in any absolute sense.

**Sources / reproduction.** `kmeans/kmeans_2024_k3|k4|k5.json`; `feature_input.csv`;
`python scripts/research_findings.py` → `investigation_3` in `findings.json` and
`tables/inv3_clusters.csv`.

## Investigation 4 — Rare-category and high-volume flags

**Research question.** What do a saved rare-category flag and a saved high-volume flag
represent, and how are their scores computed?

**Selection rule (transparent).** From the saved 2024 cross-sectional flags
(`|z| ≥ 2.5`): the rare example is the flag with the largest `|z|`; the high-volume
example is the flag with the largest observed value. No hand-picking.

**Verified results.**

| | Rare-category example | High-volume example |
|---|---|---|
| Category (context) | Abetment outside India for offence in India (Misc. IPC/Crimes) | Other Thefts/305/307 (Theft) |
| Reporting unit | Satara, Maharashtra | North-West, Delhi |
| Observed value | 1 | 13,156 |
| Cohort size | 774 | 774 |
| Zeros / fraction | 773 / 0.9987 | 13 / 0.0168 |
| Cohort mean | 0.001292 | 318.897933 |
| Cohort std (sample, ddof=1) | 0.035944 | 1,179.06442 |
| Reproduced z | **27.7849** | **10.8875** |
| Saved z | 27.7849 | 10.8875 |

**Definition.** `z = (observed − cohort_mean) / cohort_std`, where `cohort_std` is the
**sample** standard deviation (`ddof=1`), matching `analysis/.../methods/anomaly.py`.

**Independent reproduction.** The transform is recomputed from the raw feature matrix:
for the rare case the single positive value among 773 zeros makes the sample-std z
reduce to `(N−1)/√N = 773/√774 = 27.7849`, exactly the saved value. The high-volume case
reproduces to 10.8875 from full-precision values. (Reproducing from the *rounded* saved
`mean`/`std` gives 25.0 and 10.8876 respectively; the difference is purely the saved
2-dp rounding: `0.001292 → 0.0`, `0.035944 → 0.04`.)

**Figure.** [`figures/inv4_flags.png`](../analysis/output/findings/ncrb-national-2024-admin-log1p-zscore-20261107-v4/figures/inv4_flags.png)
— per-category reference distributions (log1p) with the observed value marked.

**Plain-language interpretation.** "Rare" means the category is almost always zero and a
unit recorded exactly one case, so the deviation is extreme relative to a near-constant
cohort — this is a rare-event signal, not a large number. "High-volume" means the unit
recorded a genuinely large number, far above the same category elsewhere.

**Limitation / alternative explanation.** A statistical flag is **not** a data error, not
wrongdoing, and not a risk score; it only says the value is unusual for that category in
2024. The rare example's z is inflated mechanically by the near-zero baseline.

**Sources / reproduction.** `anomalies/anomalies_2024.json`; `feature_input.csv`;
`python scripts/research_findings.py` → `investigation_4` in `findings.json`. Regression
test: [`analysis/tests/test_anomaly_convention.py`](../analysis/tests/test_anomaly_convention.py).

## Investigation 5 — Interpretable association rules

**Research question.** Which category pairs co-occur across districts, and how strong is
that co-occurrence relative to the consequent's own prevalence?

**Scope / population.** Transactions are one per administrative district; an **item is
present when that category's reported count ≥ 10**. Districts with no qualifying item
are dropped (empty transactions are excluded). Saved **N = 739**; the script rebuilds the
population from `feature_input.csv` and also gets **739** — they agree.

**Selection rule (transparent).** Single-item antecedent **and** single-item consequent,
ranked by lift, excluding ancestor/descendant (tautological) pairs; top 3.

**Verified results** (N = 739; saved = recomputed for every figure).

| # | Antecedent (context) | Consequent (context) | Ant | Con | Joint | Support | Confidence | Lift | Consequent baseline |
|---|---|---|---|---|---|---|---|---|---|
| 1 | Stalking (Women & Child) | Arson (Misc. IPC/BNS) | 184 | 218 | 123 | 0.1664 | 0.6685 | 2.2661 | 0.2950 |
| 2 | Stalking (Women & Child) | In Any other place (Sexual Harassment) | 184 | 247 | 139 | 0.1881 | 0.7554 | 2.2602 | 0.3342 |
| 3 | Dowry Death (Women & Child) | Kidnapping to compel marriage (Women & Child) | 181 | 281 | 133 | 0.1800 | 0.7348 | 1.9325 | 0.3802 |

**Independent calculation.** Support `= joint/N`, confidence `= joint/ant`,
lift `= (joint·N)/(ant·con)` — all recomputed from the rebuilt binary matrix and matching
the saved values ([`association/association_rules_2024.json`](../analysis/output/runs/ncrb-national-2024-admin-log1p-zscore-20261107-v4/association/association_rules_2024.json)).

**Figure.** [`figures/inv5_rule_baselines.png`](../analysis/output/findings/ncrb-national-2024-admin-log1p-zscore-20261107-v4/figures/inv5_rule_baselines.png)
— consequent baseline prevalence vs conditional prevalence per rule.

**Plain-language interpretation.** Lifts above 2 mean the consequent is roughly twice as
common in districts that also report the antecedent than it is overall. Baseline
prevalence is shown next to the conditional one so the increase is visible, not implied.

**Limitation / alternative explanation.** These are district-level co-occurrences; they
**do not** imply shared incidents, shared offenders, or causation. The item threshold
(≥ 10) deliberately drops very small counts, so the 739-transaction population excludes
districts whose counts are all below it — a known, documented scope choice. The mining
population and saved rules were **not** altered.

**Sources / reproduction.** `association/association_rules_2024.json`; `feature_input.csv`;
`python scripts/research_findings.py` → `investigation_5` in `findings.json` and
`tables/inv5_rules.csv`.
