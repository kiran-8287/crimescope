# CrimeScope Proposal

## Motivation
Understand regional safety through comparison of reported crime patterns, not a definitive safety ranking.

## Objective
Build a full-stack analytics dashboard (React + Node + Python) exposing regional crime patterns and trends for NCRB reported crime records 2020-2024.

## Stack
- Frontend: React + TypeScript + Vite
- Backend: Node.js + Express + TypeScript + SQLite (read-only)
- Analysis: Python (pandas, scikit-learn, mlxtend)

## Scope
Five core course functionalities: data processing, statistics, dimensionality reduction (PCA), clustering (K-means + hierarchical), outlier/anomaly analysis. Association rules if observations support a meaningful transaction design.
