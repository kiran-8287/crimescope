# CrimeScope

CrimeScope is a regional crime analytics dashboard for NCRB district-wise reported crime data. The active serving release covers 2021–2024; saved structural analyses describe the 2024 administrative-district cohort.

## Quick start

Requirements: Node.js 18+, npm 9+, and Python 3.10+ for source builds and research reproduction.

```powershell
npm install
npm --workspace backend run dev
```

In a second terminal, from the repository root:

```powershell
npm run dev
```

Open <http://localhost:5173>. The checked-in source code uses local frozen runtime artifacts that are ignored by Git. A clean clone can prepare inputs with `python scripts/download_data.py`, then use `scripts/package_handoff.ps1 -DryRun` to inspect what the local demo handoff needs. The handoff packages frozen serving and analysis artifacts; it does not include raw CSVs, source code, or dependencies. See [the handoff and reproduction guide](docs/handoff.md).

## Project map

- `frontend/` — React dashboard and nine routes.
- `backend/` — Express API and read-only SQLite access.
- `analysis/src/` — reusable Python cleaning, feature, and method code.
- `scripts/` — source download, canonical build, current analysis, findings, export, and handoff entry points.
- `config/` and `data/mappings/` — source selection, category roles, and geography/category crosswalks.
- `data/raw/` — ignored 144-file source set, checksums, and selection metadata.
- `data/serving/` and `analysis/output/runs/` — active release and analysis pointers plus frozen artifacts (ignored).
- `docs/` — [methodology](docs/methodology.md), [findings](docs/findings.md), [handoff](docs/handoff.md), [API contract](docs/api_contract.md), and [final report](docs/final_report.md).
- `progress/` — required project status and work logs.

## Reproduction and checks

The supported raw-to-canonical build is `python scripts/build_phase_c.py`. The supported active-run inspection is `python scripts/run_current_analysis.py --dry-run`; actual analysis generation requires an explicit new run ID and writes to a new isolated run directory. It does not change the serving pointer.

```powershell
python -m pytest analysis/tests scripts/test_refined_classifier.py
npm test
npm run build
```

Course methods 01–04 and 05–09 are a separate multi-year reproduction path and use the feature input generated by `run_methods_01_04.py`. That is distinct from the dashboard's frozen 2024 analysis run. See the [method-to-code map](docs/methodology.md#course-method-to-code-map).

## Notebook learning path

The notebooks explain the verified pipeline using active source files, project Python modules, and saved release/run artifacts. They do not rebuild the release or refit the active models.

1. [Data preprocessing and quality](notebooks/01_data_preprocessing.ipynb) — wide NCRB tables to canonical observations, missing cells, unit types, and quality accounting; dashboard `/quality` and `/methodology`.
2. [Descriptive statistics and trends](notebooks/02_statistics_and_trends.ipynb) — reported-count profiles, annual totals, and the name-matched comparison; dashboard `/`, `/compare`, and `/trends`.
3. [Feature preparation, PCA, and clustering](notebooks/03_pca_and_clustering.ipynb) — the 2024 feature matrix and saved PCA, K-means, and Ward results; dashboard `/pca` and `/clusters`.
4. [Anomalies and association rules](notebooks/04_anomalies_and_association_rules.ipynb) — sample-standardized cross-sectional outliers and district-profile rules; dashboard `/anomalies` and `/rules`.

For notebook environment setup, local artifacts, and exact execution commands, see the [notebook section of the handoff guide](docs/handoff.md#notebook-learning-path).

## Active data and interpretation

The serving pointer is `data/serving/current.json`; the analysis pointer is `analysis/output/runs/current.json`. Source selection and checksums are recorded in the ignored `data/raw/download_manifest_2021_2024.json`, generated by `scripts/download_data.py`. The 2020 partial Andhra Pradesh inputs are historical only. CrimeScope reports recorded counts, not crime prevalence, safety, or population-adjusted rates. The 2023 IPC and 2024 BNS years are not trended against each other.
